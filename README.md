## Digital Library (Open API Page)
My Open API project focuses on books because I love reading — it is one of my favorite hobbies.

## How to Use the Digital Library:
1. You can type the name of a book and click the button to search for all books with that title. Even if you don’t know the full name, every book containing that word will appear.
2. You can also search by the author’s name. This will display every book they have written or co‑written, including any series they may have.
3. The results also show the book’s publication year.
